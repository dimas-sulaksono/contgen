# Taruh screenshot post Instagram kompetitor di sini

Instagram tidak bisa diakses agen (login wall / jaringan). Untuk menyelesaikan analisis visual Fase 1:

1. Buka https://www.instagram.com/lapakgaming.id/ dengan akunmu sendiri.
2. Screenshot **9-12 post terbaru**. Usahakan campuran: feed promo, karakter game, reel cover, carousel (slide pertama).
3. Simpan di folder ini dengan nama `post_01.png`, `post_02.png`, dst.
4. Jika bisa, salin caption tiap post ke `captions.md` dengan format:

```
## post_01
caption: <teks penuh>
tanggal: <opsional>
jenis: image | carousel | reel
```

File di folder ini hanya dipakai sebagai bahan analisis pola. Jangan dipakai ulang sebagai aset konten.
